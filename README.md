# VoiceServerIP

Плагин для [Vencord](https://github.com/Vendicated/Vencord). Показывает адрес медиа-сервера
Discord, с которым установлено соединение:

* вход в голосовой канал или звонок;
* запуск своего стрима Go Live;
* открытие чужого стрима.

В уведомлении три строки: адрес с портом, канал, хостнейм сервера. Клик по уведомлению копирует
адрес в буфер обмена. Штатно Discord
показывает только регион сервера, а адрес виден лишь в отладочных логах, поэтому для правил
маршрутизации его приходится доставать отдельно. У голоса и у стрима адреса разные, и в правила
нужны оба: подробности в [Устройство.md](Устройство.md).

## Сборка и установка

Плагины из `userplugins` работают только в Vencord, собранном из исходников; в готовую сборку из
инсталлятора их не добавить. Нужны Node.js 22 или новее, pnpm и git.

```bash
git clone https://github.com/Vendicated/Vencord && cd Vencord && pnpm i
```

Папка `voiceServerIP` из этого репозитория копируется в `Vencord/src/userplugins/voiceServerIP`.
Пустых папок и пустых файлов в `src/userplugins` быть не должно: инициализация Vencord завершится
с `TypeError`.

```bash
pnpm build
```

```bash
pnpm inject
```

`pnpm inject` запрашивает, какую установку Discord пропатчить, и требует закрытого Discord. После
запуска плагин включается в **Настройки → Vencord → Plugins → VoiceServerIP**.

Для последующих правок плагина достаточно `pnpm build` и перезагрузки клиента по `Ctrl+R`,
повторный `inject` не нужен.

## Настройки

Уведомления включаются отдельно для голоса, своего стрима, чужого стрима и неопознанных
соединений.

В поле «Известные адреса» перечисляется то, о чём уведомлять не нужно: по одному в строке, адрес
IPv4 или подсеть вида `1.1.1.0/24`. Строка, начинающаяся с `#`, пропускается. По совпавшему адресу
уведомление не выводится, в консоли он остаётся с пометкой о пропуске.

Копируется по умолчанию только адрес, порт добавляется отдельной настройкой. Уведомление можно
оставить до закрытия вручную. Вывод в консоль DevTools включён и нужен при разборе проблем.

Стиль уведомлений, внутри окна Discord или системные, задаётся в разделе **Vencord → Notifications**.
Клик работает в обоих случаях. Время жизни уведомления разобрано в
[Устройство.md](Устройство.md).
